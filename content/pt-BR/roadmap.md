# Roadmap

> Estado e evolução planejada do projeto. Este é um **rascunho técnico aberto**, mantido em ciclos curtos,
> com limitações declaradas no próprio texto.

## Como ler este material

- **Linear** — da Parte 0 à Parte 9, como um curso.
- **Por trilha:**
  - **ML tradicional** — Partes 0, 1, 5, 6, 7.
  - **LLM/RAG** — Partes 0, 2, 4, 5, 6.
  - **Agentic AI** — Partes 0, 3, 4, 5, 7.
- **Por consulta** — capítulos padronizados (objetivo, conceito, produção, trade-offs, riscos,
  observação, teste, checklist) para referência rápida.

Há também um fio condutor narrativo — o estudo de caso fictício **Hermes Logística** (Cap. 0.9).

## Fases do projeto

| Fase | Entregável | Estado |
|---|---|---|

## Estado dos exemplos

Os **exemplos práticos** (`EX-*`) ainda **não foram implementados**; estão planejados, com prioridade e
ordem sugerida. O repositório **não deve ser tratado, hoje, como coleção executável de exemplos**.
